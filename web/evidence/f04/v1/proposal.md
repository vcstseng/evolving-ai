# F04｜Gen 2 方案 v1：先查材料成本，不因總額下降就稱改善

日期：2026-11-15。新合成成本案例；Gen 2 原方法、六步半自動交付；外部審查待進行。同一對話協助模型角色，作者知道設計，不是乾淨模型／獨立 Agent 或未見測試。沒有 Gen 3 閘門或新能力。

## 結論與原題回答
**總額下降不代表成本控制改善。應先核對標準接頭的材料價格與批次成本，其次高壓接頭；目前沒有足夠依據減人或替換材料。**

### 1. 總成本下降，是改善嗎？
| 按提供的每單位成本模型 | 合成金額 |
|---|---:|
| 原始基準 | 75,000 |
| 實際 | 70,700 |
| 表面總差異 | −4,300 |
| 按各產品實際產量調整的基準 | 66,000 |
| 產量效應（先以基準單位成本估值） | −9,000 |
| 剩餘非產量差異 | +4,700 |

75,000 − 9,000 + 4,700 = 70,700。總額較低主要因標準接頭產量從 1,000 降到 800；高壓接頭仍為 500。指定基準下其他差異是增加成本，而非改善。量下降是否符合需求仍未知，不把少做產品當節省成果。

| 產品 | 基準單位成本 | 實際單位成本 | 指定基準下非產量差異 |
|---|---:|---:|---:|
| 標準接頭 | 45 | 49 | +3,200 |
| 高壓接頭 | 60 | 63 | +1,500 |

兩產品的單位成本均提高。原始總差異為負，不以它當分母製造改善百分比或優先序。

### 2. 應優先查什麼？
| 固定順序橋接 | 歸因 | 判斷 |
|---|---:|---|
| 產量 | −9,000 | 獨立列出；需求與未來訂單另查。 |
| 材料單價 | +7,900 | 唯一正向因素，先查。標準接頭 +6,400，高壓接頭 +1,500。 |
| 每單位工時 | −3,200 | 有利抵銷，不是本題的成本增加優先項；不證明效率改善或冗員。 |
| 材料耗用、人工率、其他每單位費用 | 0 | 本資料沒有橋接差異，不推論其他期間無問題。 |

720 種順序下，材料單價歸因為 +7,900～+9,500，平均 +8,700，仍是唯一正向因素。工時為 −4,000～−3,200，平均 −3,600；量效應為 −10,600～−8,200，平均 −9,400。這些是交互項分配敏感度，不是信賴區間，不替代上面的指定彈性基準，也不證明原因或可避免金額。

先查標準接頭主要材料的一組可比基準／實際批次：相同規格、合約／發票、運費／折扣、加權成本與庫存流轉。若只是記帳口徑或批次時點，先修對帳與基準；若確有同口徑價格變動，再討論採購選項。不因材料價格歸因大，就宣稱供應商不合理或有等額節省。

### 3. 能否減人或換便宜材料？
**目前不支持。** 未有人員配置、實際負荷或未來訂單，工時下降不是減人的證據。替代材料也沒有相同品質、安全及交期驗證，不能把便宜視為可接受替代。

建議一個有界只讀調查，所有限制均待人類批准：
- 限標準接頭主要材料的一組可比批次。
- 兩個工作日或四人時先到即收尾。採購兩小時、財務一小時、品質半小時、案件擁有者半小時；包含協調、取資料、分析與記錄。
- 最低交付：對價格／批次／口徑各假設列支持、反證、未知及來源。拿不到資料可以交「證據不足」，不能編根因。
- 需額外資料管理人員、超時或超範圍時，先另申請；不自動追加工時。
- 後續供應替換、人力改變或現場試點另案核定；完整成本、品質、安全、交期、量測與人類授權缺一就不啟動。

可選擇只監測及補資料，代價是尚未回答價格原因；建議先做上述小範圍對帳，而非全面改善專案。本輪沒有啟動任何調查或實施。
