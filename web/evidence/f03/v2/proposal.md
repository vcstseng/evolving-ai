## 選項與取捨
- **只維持監測**：投入較低，但未能回答較大的非產量差異；若資料無法取得或變動經證實合理，可選此路徑並保留限制。
- **限定範圍的只讀調查**：建議採用；限單一產品及一組可比工單，先釐清口徑、必要工時與可能損失。
- **直接現場試點或全面改造**：缺根因、授權、預算與品質安全門檻，不採用；不是因工時歸因大就有理由推行。

## 有界調查、關卡與停止

### 1. 先確認調查能否啟動
- 負責人：人類案件擁有者（待指派）
- 範圍：先限驅動馬達及一組可比工單；營運與財務各一位負責人。
- 建議投入與期限（待確認）：建議人類同意啟動後五個工作日設決策點，財務與營運各最多半個工作日。這是待確認的提案，不是已批准預算或已投入工時。
- 最低證據：兩期日期、良品單位與工時定義、可比工單及成本範圍。
- 停止條件：到決策點仍拿不到最低證據，交付證據不足的受限結論；停止或另行申請延長，不自動擴大調查。

### 2. 核對可比性再查工時
- 負責人：財務與營運負責人（待指派）
- 行動：先檢查期間與工時記錄／分攤；若一致，再比較相同規格與批量下的必要工時和損失工時。
- 判斷分支：若只是合理規格／批量差異，更新基準並監測；若不能證明可控制原因，不試點。

### 3. 其次核對工資率與有利材料差異
- 負責人：財務與品質負責人（待指派）
- 行動：查薪酬範圍、加班、人員組合及品質，避免率差被誤解為應降薪或材料改善已成立。
- 判斷分支：資料不足即記為未知，不將材料有利差異當作其他改善的資金來源。

### 4. 僅在原因成立後提出可逆試點
- 負責人：人類案件擁有者與品質安全負責人（待指派）
- 進入條件：可追溯證據支持可控制原因、可比較的量測設計、完整預算及人工授權均具備。
- 驗收與停止：試點前另外確認改善與品質、安全、交期門檻。門檻未確認不啟動；觸及已確認品質安全界線就停止並回復。
- 不採用的判準：不以單一歸因佔比取代根因及授權判斷。

以上調查範圍、五個工作日與人力上限都是待問題擁有者確認的提案，不是已核定的期限、費用或已量測投入；本 run 沒有執行現場調查。
