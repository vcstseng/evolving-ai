# 方案 v3 補充 1｜依本次複審釐清三點

2026-11-15。原 v3 文件與 manifest 不改；本補充不是新六步重跑或企業授權。來源見 review-v3/review-and-response.md。

1. **固定製造費用情境**：原始每單位模型的製造費用歸因為零。若改採 X 固定費用池，基準為 500×20=10000、實際為 600×20=12000，另有池額 +2000（+20%）待核對；不能把原模型的「零歸因」沿用到這個新模型。需查費用池、分攤基礎與成本範圍，不能直接稱新增浪費。
2. **九人時範圍**：包含指定財務／營運／品質三方的協調、取資料、分析與記錄。案件擁有者核准，以及需另找 ERP／資料管理人員的協助尚未估列，所以九人時不是完整企業總成本。啟動前先由案件擁有者確認這些額外投入是否可行；若須額外人員，先補範圍、估工及授權，不以原九人時掩蓋追加成本或自動擴編。
3. **接受證據不足的結局**：五日或上限先到，可交支持／反證／未知、缺失來源、受影響決策、最小補資料要求與是否值得再投入。即使未找出根因，也能避免未支持的試點、揭露證據取得成本，協助選擇停止或另案補查；不是必須得出改善機會才算交付。但這仍不表示原問題已完整解決。
