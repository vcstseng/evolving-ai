# 概念草案｜The Evolving Firm

日期：2026-11-14。

## 核心
讓 AI 組織處理企業問題，從執行與審查中辨識能力缺口，再透過取得資料、工具、方法、調整分工或建立角色來補足。有效改變保留，並在後續案件驗證能否重用。

核心循環：案件 → 初始方案 → 檢查與審查 → 缺口診斷 → 能力改變 → 重測 → 下一案重用。

## 組織形式
沿用既有 Consulting Agent Framework 的 16 種專業角色規格，按案件選用，不代表本專案已部署或驗證全部角色。

三層責任：專業執行（明確分析模組）、案件整合（組隊、矛盾與交付）、能力發展（跨案件缺口與能力生命週期）。A01 為案件整合起點；A02 與 A15 提供橫向證據與評估支援；能力發展責任另行設計。

Junior／Senior／Manager／Director／Partner 為早期討論的例子，不是固定職級需求。人類保留真實授權與重大取捨。

## 缺口處理
先分辨執行錯誤、資料不足、方法不適、交接失敗、工具缺口與專業缺口。可以重派工、補資料、補工具、修改方法、招募現有角色或建立新角色；允許停止。新增 Agent 不是預設答案。

## Review
Claude 可作外部模型審查者，但不是最終真理。審查需指出位置、理由、證據、修正要求與不確定性。數字與硬性限制另用程式或來源查核。真實成效需要問題擁有者或實施結果支持。

## 題目變化
後續案件、新限制與受約束的合成變體可測試能力邊界。真實案件與合成變體清楚標示。固定保留未參與改進的測試案例。

## 第一版
定位為可行性與質性案例研究。先觀察能否診斷缺口、做出合理改變並有效重用，不宣稱組織架構勝過一般 Agent。候選限制：一個主要案件、少量回測／未見案例、有限改進輪數與能力候選。

## 待決定
首個案件、可用資料、評估規則、模型與工具、預算及執行方式均未確定。

## 長期成功訊號
下一個案件因過往經驗而改善，且能說明重用了什麼、在哪些條件有效、成本是否值得、何時失效。
